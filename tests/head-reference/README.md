# Sunflower development reference

`sunflower-256x190.rgba` is row-major 8-bit RGBA, 256 × 190, resized with Pillow thumbnail from the Commons thumbnail in source.json. Author Wilfredor, CC0. See source.json for exact Commons source and licence. Original colour retained, alpha opaque. This is a development regression example, not held-out accuracy evidence. Masks were visually inspected: centre mostly follows dark disc, outer region follows yellow rays; fine boundaries remain approximate.
